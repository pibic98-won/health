# NSOFT N-MES — 15초 모션그래픽

`nsoft_nmes_15s.mp4` — 1920×1080 (16:9), 60fps, H.264 + AAC 320k, 정확히 15.00초. 유튜브에 바로 업로드할 수 있습니다.
`thumbnail.jpg` — 1280×720 썸네일.

## 구성 (128 BPM · 8마디 · 모든 컷이 비트에 맞음)
| 시간 | 장면 |
|---|---|
| 0.0–1.9s | **현장의 / 모든 순간을** — 단어가 비트마다 꽂히고, 스캐너 빔이 글자를 도트로 디지털화 |
| 1.9–3.8s | 도트가 날아가 **데이터로.**를 만들고, 원근 그리드 바닥과 실시간 수치 콜아웃 표시 |
| 3.8–5.6s | 한 점으로 수렴했다가 폭발하며 **N-MES / 제조실행시스템** 등장, 하이픈 속으로 줌 인 |
| 5.6–7.5s | **4M** 패널(자재·설비·작업방법·작업자)이 비트마다 떨어지고, 블라인드처럼 빠져나감 |
| 7.5–9.4s | **실시간 모니터링** 대시보드 (실적 차트, 가동률 게이지, 생산량 카운터, 설비 상태) |
| 9.4–11.3s | 휩 팬 → **바코드 스캔** → **LOT 추적 · 역추적** 체인 |
| 11.3–13.1s | **입고 → 생산 → 품질 → 납품**, 한 박자에 한 단어, 스터터 빌드업 |
| 13.1–15.0s | 임팩트 → **N-MES** 로고 + "현장의 모든 순간을, 데이터로." + NSOFT |

문구는 엔소프트 N-MES 소개 페이지(4M 수집, 실시간 모니터링, LOT 추적, 바코드 기반 관리)를 바탕으로 했습니다. 대시보드 숫자는 연출용 예시 값이며 실적 수치가 아닙니다.

## 다시 만들기
```bash
./fetch_fonts.sh                                   # Google Fonts (OFL)
python3 audio.py                                   # audio.wav (numpy로 사운드트랙 합성)
NODE_PATH=$(npm root -g) node render.cjs frames 3 4   # out/frames (워커 3개, 모션블러 샘플 4개)
./make_video.sh                                    # nsoft_nmes_15s.mp4 (pip install imageio-ffmpeg)
```
미리보기: 이 폴더를 서버로 띄운 뒤 `index.html?play`를 열면 되고, 단일 프레임은 `index.html?t=7.5`로 볼 수 있습니다.
