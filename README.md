# 한달 운동 챌린지

30일 운동 실천 여부를 체크하는 웹 앱입니다. 서버나 빌드 도구 없이 `index.html` 파일 하나로 동작하며, 진행 기록은 브라우저의 localStorage에 저장됩니다.

## 사용법

`index.html`을 브라우저로 열면 됩니다. GitHub Pages 등 정적 호스팅에 그대로 올려도 동작합니다.

1. "시작하기"를 누르면 오늘부터 1일차로 30일 챌린지가 시작됩니다.
2. 매일 오늘의 미션 4가지를 체크합니다.
3. 하단 달력에서 하루씩 완료 현황(미완료/일부 완료/전체 완료)을 확인하거나, 지난 날짜를 눌러 놓친 기록을 수정할 수 있습니다.
4. 30일이 지나면 완료 화면이 표시되며, 새 챌린지를 다시 시작할 수 있습니다.

## 운동 계획

- 스쿼트 30개 (3일마다 5개씩 증가)
- 덤벨 · 케틀벨 운동 5분
- 철봉 매달리기 10초 × 3회 (3일마다 5초씩 증가)
- 칠천보 걷기
